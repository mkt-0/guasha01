# 刮痧工作室预约仪表盘（iPhone专用版）

## 完全不用电脑，只用iPhone

### 第一次设置（只需一次）
1. 用 **iPhone的Safari浏览器** 打开这个页面的链接
2. 点屏幕底部的 **分享按钮**（方框+向上箭头）
3. 向下滑动，点 **「添加到主屏幕」**
4. 名称可以改成「刮痧预约」，点右上角「添加」

之后从手机桌面的图标直接打开，就像普通APP一样，不用再打开浏览器。

### 日常使用（爸妈只需要会这几步）
1. 打开桌面图标
2. 看上面「今日预约」（黄色的是今天的）
3. 点大按钮「添加新预约」→ 填客人姓名、选日期时间 → 保存
4. 保存后会问是否添加到日历 → 选「确定」
5. 手机会自动打开日历，点右上角「添加」就完成（已经设置了提前30分钟和10分钟提醒）

### 提醒怎么来的？
- 靠iPhone自带的「日历」APP发通知，非常可靠
- 不需要一直开着这个页面
- 提醒会在锁屏和通知中心出现

### 其他功能
- 「复制今日名单」：一键复制今天所有客人，直接粘贴到微信发给客人确认
- 修改、删除预约都很简单

### 注意事项
- 请一直用Safari打开（不要用微信内置浏览器添加主屏幕，效果不好）
- 数据存在这台iPhone里，换手机需要重新添加
- 建议把这个页面链接收藏好，或者发给自己微信置顶
